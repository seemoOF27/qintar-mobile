# قنطار — الموبايل

تطبيق React Native (Expo) يستهلك نفس الـAPI الذي يستهلكه الويب، بلا تكرار
في الخلفية ولا منطق مالي هنا.

**المرجع التقني كله في مستودع `qintar-backend`.** اقرأ `CLAUDE.md` قبل أي عمل.

---

## التشغيل محليًّا

```bash
npm install
cp .env.example .env          # وضع عنوان الخادم فيه
npm start                     # ثم i للآيفون أو a للأندرويد
```

`npm start` يولّد `src/theme.ts` من `shared/design-tokens.json` أولًا، فلا
يمكن أن يتباعد الملفان.

## الاختبارات

```bash
npm test          # ١٩ حارسًا معماريًّا
npm run typecheck
npm run shared:check
```

كلها حرّاس لا اختبارات واجهة: لا Hex مكتوبًا يدًا، ولا `parseFloat` على مبلغ،
ولا حزمة مراقبة، ولا رمز في مخزن غير آمن، ونصوص الموافقة مطابقة للخلفية
حرفيًا. **وكل واحد منها أُثبت فشله بخرق متعمّد** قبل أن يُعتمد.

## جرّبه على آيفونك الآن — مجانًا، بلا حساب Apple

١. ثبّت **Expo Go** من App Store على الآيفون (يحتاج iOS 16.4 فأعلى).

٢. الماك والجوال على **نفس شبكة Wi-Fi**.

٣. شغّل الخادم ليستمع على الشبكة، ثم التطبيق:

```bash
cd api && php artisan serve --host=0.0.0.0 --port=8000     # نافذة ١
cd api && php artisan queue:work --tries=1                  # نافذة ٢
cd mobile && npm run phone                                  # نافذة ٣
```

٤. افتح **كاميرا الآيفون** ووجّهها على الرمز الذي يظهر في النافذة الثالثة.

`npm run phone` يقرأ عنوان الماك على الشبكة ويمرّره للتطبيق تلقائيًا —
`127.0.0.1` على الجوال يعني الجوال نفسه لا الماك.

**وإن لم يصل الجوال للخادم** (شبكة عمل أو جدار حماية)، استخدم النفق في
`qintar-backend/docs/deploy.md` وشغّل:

```bash
EXPO_PUBLIC_API_URL=https://عنوان-النفق npx expo start --tunnel
```

**حدود Expo Go:** يحتاج التطبيق مفتوحًا داخله، ولا يعطيك أيقونة مستقلة
على الشاشة الرئيسية. للأيقونة المستقلة على الآيفون يلزم حساب Apple Developer.

**لماذا لا محاكي:** Xcode المثبَّت على هذا الماك (14.1) يأتي بـiOS 16.1،
وExpo Go الحالي يحتاج 16.4. ترقية Xcode تكفي إن أردت المحاكي.

## البناء والتثبيت

التفاصيل الكاملة في `qintar-backend/docs/deploy.md` — الأوامر والحسابات
والتكاليف.

| الحالة | الأمر |
|---|---|
| تجربة على جهازك بلا حساب | `npx expo start` ثم Expo Go |
| APK للأندرويد يُثبَّت مباشرة | `eas build -p android --profile preview` |
| iOS إلى TestFlight | `eas build -p ios --profile production` ثم `eas submit` |

**عنوان الخادم يُخزَّن في الحزمة وقت البناء.** تغييره يحتاج بناءً جديدًا —
ولذلك `eas.json` فيه ثلاث بيئات لا واحدة.

## ما ليس هنا

إنشاء الميزانيات والحصالات وتعديل نسب الاقتطاع وحذف الحساب: شاشات إعداد
طويلة تُضبط مرة، وتكرارها في تطبيق جوال يضاعف سطح الخطأ في أرقام مالية بلا
فائدة تُذكر. مكانها الويب.

وقارئ إشعارات البنك وويدجت الشاشة الرئيسية مؤجَّلان — `PROJECT_CONTEXT.md`
